**gdb** (GNU Debugger) нь программыг алхам алхмаар ажиллуулж, доторх функц, регистр,
санах ойг харах хэрэгсэл. **[pwndbg](https://github.com/pwndbg/pwndbg)** нь gdb дээр суудаг нэмэлт бөгөөд
регистр, код, stack-ийг өнгөтэй, нэг дор харуулдаг. Pwn бодлогод бид pwndbg ашиглана.

Энэ хуудсанд бүх жишээг доорх энгийн программ дээр үзүүлнэ:

```c title="hello.c"
#include <stdio.h>

int add(int a, int b) {
    int sum = a + b;
    return sum;
}

int main(void) {
    int x = add(2, 3);
    printf("2 + 3 = %d\n", x);
    return 0;
}
```

```console
$ gcc hello.c -o hello -no-pie
$ gdb ./hello
pwndbg>
```

:::tip
pwndbg суулгах: [github.com/pwndbg/pwndbg](https://github.com/pwndbg/pwndbg#how).
gdb асахад удаж байвал `~/.gdbinit`-д `set debuginfod enabled off` гэж нэм.
:::

## Функцүүдийг харах

`info functions <нэр>` — нэр нь таарсан функцүүд болон тэдгээрийн хаягийг харуулна.
Нэр өгөхгүй бол бүх функцийг (libc-ийнхийг оролцуулан) жагсаана.

```ansi
[1;31mpwndbg>[0m info functions add
All functions matching regular expression "add":

Non-debugging symbols:
[34;49;22;23;24;27m0x0000000000401136[m  [33;49;22;23;24;27madd[m[0m
```

Нэр нь regex тул яг таарахыг хайвал `^` ба `$` ашигла:

```ansi
[1;31mpwndbg>[0m info functions ^main$
All functions matching regular expression "^main$":

Non-debugging symbols:
[34;49;22;23;24;27m0x0000000000401154[m  [33;49;22;23;24;27mmain[m[0m
```

Унших нь:

- Зүүн талын тоо — зааврын **хаяг**. `<+8>` нь функцийн эхнээс хэдэн байтын зайтайг заана.
- `push rbp` / `mov rbp,rsp` — функцийн эхлэл (prologue): шинэ stack frame үүсгэнэ.
- `[rbp-0x14]`, `[rbp-0x18]` — stack дээрх локал хувьсагчид. `rbp`-ээс хэр зайтайг эндээс уншина.
- `edi`, `esi` — x86-64 дээр эхний хоёр аргумент (`a`, `b`) эдгээр регистрээр ирдэг.
- `eax` — буцах утга (`return sum`).
- `ret` — функцээс буцна.

## Breakpoint тавьж ажиллуулах

`break` (`b`) — программыг тухайн газар зогсооно. `run` (`r`) — программыг эхлүүлнэ.

```ansi
[1;31mpwndbg>[0m break add
Breakpoint 1 at [34;49;22;23;24;27m0x40113e[m[0m
[1;31mpwndbg>[0m run
Breakpoint 1, [34;49;22;23;24;27m0x000000000040113e[m in [33;49;22;23;24;27madd[m ()[0m
```

Хаягаар ч breakpoint тавьж болно: `break *0x40114a` (`*` тэмдэг заавал).

  **буцах хаяг (return address)** юм.
- **BACKTRACE** — одоо ямар функцүүдээр дамжиж ирснийг харуулна.

## Pwn-д хэрэгтэй командууд

Доорх командууд pwn бодлогод байнга хэрэг болно. Эхний хэдийг [ret2text](../../userland/ret2text/) binary дээр үзүүлнэ.

### distance — хоёр хаягийн зөрүү

`distance a b` нь хоёр хаягийн хоорондох зайг (offset) шууд бодож өгнө — гараар тооцоолох шаардлагагүй.
`vuln+34` дээр (`gets` дуудахын өмнө) зогсоход `rdi` = `buf`, return address нь `rbp+8`-д байна:

```ansi
[1;31mpwndbg>[0m distance $rdi $rbp+8
[33m0x7fffffffde10[0m->[33m0x7fffffffde58[0m is 0x48 bytes (0x9 words)
```

`0x48` = **72** — энэ бол яг [ret2text-ийн offset](../../userland/ret2text/#4-offset-олох). cyclic pattern ашиглахгүйгээр
хоёр хаягийн зөрүүгээр offset-ийг шууд уншиж болно.

### search — санах ойгоос хайх

`search` нь санах ойгоос байт, тэмдэгт мөр, заагчийг хайна. ret2libc-д хэрэгтэй `/bin/sh` мөрийг хайх жишээ:

```ansi
[1;31mpwndbg>[0m search -t bytes "/bin/sh"
Searching for byte: b'/bin/sh'
[0mret2text       [0m [0m0x402022[0m 0x68732f6e69622f /* '/bin/sh' */
[0mret2text       [0m [0m0x403022[0m 0x68732f6e69622f /* '/bin/sh' */
[0mlibc.so.6      [0m [0m0x7ffff7ddb799[0m 0x68732f6e69622f /* '/bin/sh' */
```

`binary` болон `libc` дотроос олдлоо. Зөвхөн нэг хэсгээс хайх бол `search -t bytes "/bin/sh" libc` гэнэ.

### retaddr — return address-ууд

`retaddr` нь stack дээр return address агуулж буй бүх нүдийг олж харуулна. Overflow-оор дарах зорилтоо хурдан олоход тустай:

## Heap командууд

pwndbg-ийн хамгийн хүчтэй тал нь **heap**-ийн төлөвийг харуулдагт бий. (Энэ wiki-д одоогоор heap бодлого байхгүй
ч командуудыг танилцуулж байна.) Доорх жишээнд гурван chunk `malloc` хийгээд хоёрыг нь `free` хийсэн:

```c title="heapdemo.c"
char *a = malloc(0x18);  strcpy(a, "AAAA");
char *b = malloc(0x28);  strcpy(b, "BBBB");
char *c = malloc(0x18);  strcpy(c, "CCCC");
free(a);
free(c);
```

`bins` нь чөлөөлөгдсөн chunk-ууд аль bin-д байгааг харуулна. Free хийсэн chunk эхлээд **tcache**-д ордог:

сүүлд free хийсэн нь (`c`) эхэнд байна (LIFO).
