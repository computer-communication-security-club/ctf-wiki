**gdb** (GNU Debugger) нь программыг алхам алхмаар ажиллуулж, доторх функц, регистр,
санах ойг харах хэрэгсэл. **[pwndbg](https://github.com/pwndbg/pwndbg)** нь gdb дээр суудаг нэмэлт бөгөөд
регистр, код, stack-ийг өнгөтэй, нэг дор харуулдаг. Pwn бодлогод бид pwndbg ашиглана.

Энэ хуудсанд бүх жишээг доорх энгийн программ дээр үзүүлнэ:

```c title="hello.c"
#include <stdio.h>

int add(int a, int b) {
    int sum = a + b;
    return sum;
}

int main(void) {
    int x = add(2, 3);
    printf("2 + 3 = %d\n", x);
    return 0;
}
```

```console
$ gcc hello.c -o hello -no-pie
$ gdb ./hello
pwndbg>
```

:::tip
pwndbg суулгах: [github.com/pwndbg/pwndbg](https://github.com/pwndbg/pwndbg#how).
gdb асахад удаж байвал `~/.gdbinit`-д `set debuginfod enabled off` гэж нэм.
:::

## Функцүүдийг харах

`info functions <нэр>` — нэр нь таарсан функцүүд болон тэдгээрийн хаягийг харуулна.
Нэр өгөхгүй бол бүх функцийг (libc-ийнхийг оролцуулан) жагсаана.

```ansi
[1;31mpwndbg>[0m info functions add
All functions matching regular expression "add":

Non-debugging symbols:
[34;49;22;23;24;27m0x0000000000401136[m  [33;49;22;23;24;27madd[m[0m
```

Нэр нь regex тул яг таарахыг хайвал `^` ба `$` ашигла:

```ansi
[1;31mpwndbg>[0m info functions ^main$
All functions matching regular expression "^main$":

Non-debugging symbols:
[34;49;22;23;24;27m0x0000000000401154[m  [33;49;22;23;24;27mmain[m[0m
```

Унших нь:

- Зүүн талын тоо — зааврын **хаяг**. `<+8>` нь функцийн эхнээс хэдэн байтын зайтайг заана.
- `push rbp` / `mov rbp,rsp` — функцийн эхлэл (prologue): шинэ stack frame үүсгэнэ.
- `[rbp-0x14]`, `[rbp-0x18]` — stack дээрх локал хувьсагчид. `rbp`-ээс хэр зайтайг эндээс уншина.
- `edi`, `esi` — x86-64 дээр эхний хоёр аргумент (`a`, `b`) эдгээр регистрээр ирдэг.
- `eax` — буцах утга (`return sum`).
- `ret` — функцээс буцна.

## Breakpoint тавьж ажиллуулах

`break` (`b`) — программыг тухайн газар зогсооно. `run` (`r`) — программыг эхлүүлнэ.

```ansi
[1;31mpwndbg>[0m break add
Breakpoint 1 at [34;49;22;23;24;27m0x40113e[m[0m
[1;31mpwndbg>[0m run
Breakpoint 1, [34;49;22;23;24;27m0x000000000040113e[m in [33;49;22;23;24;27madd[m ()[0m
```

Хаягаар ч breakpoint тавьж болно: `break *0x40114a` (`*` тэмдэг заавал).

- **REGISTERS** — `*` тэмдэгтэй регистр сүүлийн алхамд өөрчлөгдсөн. `RDI = 2`, `RSI = 3` нь `add(2, 3)`-ийн аргументууд.

- **DISASM** — `►` нь одоогийн заавар. Баруун талд pwndbg заавар юу хийхийг урьдчилж тооцоолно (`EAX => 5 (3 + 2)`).
- **STACK** — `rbp + 8` (`01:0008│+008`) дээр `0x40116f (main+27)` байна. Энэ бол `add` дуусахад `main` руу
  **буцах хаяг (return address)** юм.
- **BACKTRACE** — одоо ямар функцүүдээр дамжиж ирснийг харуулна.

`x/<тоо><формат> <хаяг>` — санах ойг шууд уншина:

## Алхам алхмаар ажиллуулах

| Команд | Үйлдэл |
|--------|--------|
| `ni` | Дараагийн заавар (функц руу орохгүй) |
| `si` | Дараагийн заавар (`call` бол функц руу орно) |
